# Documentation Index

This directory contains two layers of documentation.

- `agent/` holds measured working notes. Agents wrote these notes. They are the source of truth for measurements.
- `human/` holds the readable layer. It uses ASD-STE100 Simplified Technical English.

Start with [`human/README.md`](human/README.md). Open `agent/` when you need the raw measurement or the reasoning behind a decision.
